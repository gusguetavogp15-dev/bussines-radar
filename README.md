# Bussines Radar

Radar de oportunidades de negocio: ideas puntuadas con interés real (Wikipedia), los productos
más vendidos (Amazon y Walmart), lo más buscado en Google (Rep. Dominicana y EE.UU.) y noticias
de economía, cada idea con sus proveedores.

- **Web:** se publica en GitHub Pages y se actualiza sola cada día a las 7:00 (hora de RD)
  con el flujo `.github/workflows/actualizar.yml`. Para actualizar a mano: pestaña *Actions* →
  *Actualización diaria* → *Run workflow*.
- **En la Mac:** doble clic en `Abrir Radar.command` (refresca cada hora mientras está abierta).

Inversión, margen, ROI, el "potencial" de los productos y las ideas sugeridas son estimaciones.
No es asesoría financiera.
